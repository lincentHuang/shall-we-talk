# Shall We Talk・聊聊好嗎

一副讓話題慢慢變深的對話卡牌 App。用 Expo（React Native）製作，iOS、Android、網頁共用同一份程式碼。

## 一局的流程

1. **準備**：選談話對象、輸入一起玩的人（2–8 位，照順序輪流）、聊天情境與話題主題
2. **開場**：一個人念出開場白，大家放下手機、進入狀態（第一次玩會先看「怎麼玩」）
3. **分層抽牌**：牌分成 ✧ 暖身破冰 → I 淺談 → II 走心 → III 深談（依情境而定），一層抽完才進入下一層；聊得夠了也可以直接往下一層
4. **回答與接話**：輪到的人回答；不想答可以「換一張」（不算輪過），或「請別人答」。其他人可以看「接話小抄」追問、回饋、引導深入
5. **收尾分享**：最後一張是收尾分享卡；可以「回顧這一局」把喜歡的題目收藏起來，也能隨時提早收尾

## 功能

- **談話對象**：朋友、曖昧對象、戀人・伴侶、家人、同事、新朋友、我自己；牌桌上會顯示「輪到誰抽牌／回答」
- **聊天情境**：咖啡廳小聊、深夜長聊、散步漫談、微醺餐桌、旅途之中、朋友聚會——情境決定題目深度（I 淺談／II 走心／III 深談）與張數
- **話題主題**：初見破冰、回憶與成長、價值與信念、愛與關係、夢想與未來、真心與脆弱、假如與奇想，可複選或「完全隨機」；每個主題都有淺談、走心、深談三層題目，暖身層則是另外一組十秒內答得出來的輕鬆題
- **兩人或多人**：題目裡的「你」一律是答題的人；兩個人時會問到「對方」，三人以上換成「左手邊這位」，另有「在場的人裡，誰最⋯」這類多人限定題
- **互動野卡**：穿插在各層裡「大家一起做一件事」的卡，深淺跟著那一層走（淺談是合照、點歌，深談是說出想謝謝的事）
- **挑牌**：洗好的這一層牌攤成扇形手牌（像抽鬼牌），手指在牌上左右滑動，指到的那張會浮起來並輕震一下；往上拉出、或再點一下就抽到它。不想挑也可以按「隨機抽一張」
- **動態**：兩輪鴿尾式洗牌、扇形攤牌、3D 翻牌＋金色星芒、左右滑走；搭配音效與觸覺回饋
- **收藏**：喜歡的題目按 ♡，在首頁「我的收藏」查看

## 開發

```bash
npm install
npx expo start          # 手機用 Expo Go 掃 QR code
npx expo start --web    # 網頁版
npm run typecheck
```

網頁版：滑鼠移到牌上就會挑起那張，點一下抽出。快捷鍵：←／→ 挑牌，空白鍵／Enter／↑ 抽牌（翻開後按空白鍵／Enter／→ 換下一張），S 重新洗牌。

## 專案結構

```
src/app/            畫面（Expo Router）：index 首頁、setup 準備牌局、play 牌桌、favorites 收藏
src/components/     卡牌、扇形手牌（FanHand）、洗牌動畫（ShuffleLayer）、按鈕、面板
src/data/           catalog（對象／情境／主題／分層）、questions（題庫）、guide（開場白、接話小抄、收尾分享）
src/lib/            deck（分層組牌、玩家名單）、storage（收藏與設定）、feedback（音效與震動）
assets/cards/       卡背與 8 種卡面美術
assets/scenes/      情境插畫
assets/fonts/       已子集化的思源宋體與 Cormorant Garamond
art-source/         美術原始大圖與完整字型（不會打包進 App）
```

## 新增或修改題目

題目在 `src/data/questions.ts`，格式為 `[編號, 層, 題目, 適用對象?]`：

- 編號：收藏靠它對應題目，寫好就不要改；新增題目往後編，刪掉的編號不要再用
- 層：`0` 暖身（十秒內答得出來）、`1` 淺談（日常和喜好）、`2` 走心（經歷和感受）、`3` 深談（比較少說出口的事）
- 題目裡的「你」是答題的人；要問到另一個人時寫 `{TA}`，兩人時會顯示「對方」，三人以上顯示「左手邊這位」
- 適用對象（可省略，省略代表連「我自己」都能用）：`'others'` 要有別人在場、`'duo'` 只限兩人、`'group'` 三人以上、`'known'` 需要已經認識、`'romance'` 曖昧或戀人（兩人）、`'couple'` 只限戀人（兩人）

中文字型為了縮小檔案只保留用到的字。**新增題目後請執行一次：**

```bash
npm run fonts
```

否則新出現的字會改用系統字型顯示。

## 美術

卡牌美術以使用者提供的參考圖風格（新藝術運動、慕夏風、薰衣草紫與土耳其藍、金色秋葉）透過 AI 生成；音效同樣為 AI 生成。原始檔放在 `art-source/`。
